# Quick Start: Time-Based Chat Access

## For Creators: How to Set Up

### Option 1: Fast Testing (Recommended for Development)
1. Go to **Profile Settings**
2. Under **Chat Access & Pricing**:
   - **Time Unit**: Select **Minutes**
   - **Access Duration**: Enter **5**
   - **Price**: Enter **$1** (for testing)
3. Click **Save changes**
4. Test with a fan account - access expires in 5 minutes!

### Option 2: Short Sessions (1-24 hours)
1. Go to **Profile Settings**
2. Under **Chat Access & Pricing**:
   - **Time Unit**: Select **Hours**
   - **Access Duration**: Choose from presets (1, 6, 12, 24 hours)
   - **Price**: Set your price ($10-$100 typical)
3. Click **Save changes**

### Option 3: Standard Tiers (Days/Weeks/Months)
1. Go to **Profile Settings**
2. Under **Chat Access & Pricing**:
   - **Time Unit**: Select **Days**
   - **Access Duration**: Choose preset (7, 14, 30 days) or custom
   - **Price**: Set your price ($50-$500 typical)
3. Click **Save changes**
